# Eco-Loop Building Agents

Autonomous closed-loop building energy control PoC for the Honeywell Hackathon.

EnergyPlus (physics-based simulation) is paired with an open-source LLM agent
(via Ollama) through a tool-calling / MCP-style control bus. The agent reads
live zone telemetry every simulation timestep, reasons about comfort +
energy targets, and injects new setpoints back into the running simulation.

```
EnergyPlus (EMS callback) --sensors--> Telemetry Bus --> LLM Agent (tools) --actuators--> EnergyPlus (EMS callback)
```

## Quick start

### 1. Install EnergyPlus (v23.x or v24.x recommended)

Download from https://energyplus.net/downloads for your OS. After install,
note the install directory — on Linux it's typically `/usr/local/EnergyPlus-24-1-0`,
on Windows `C:\EnergyPlusV24-1-0`. That directory contains `energyplus`
(the binary) and the `pyenergyplus` Python package.

Add it to your Python path (also handled in `energyplus_wrapper.py`):

```bash
export ENERGYPLUS_DIR=/usr/local/EnergyPlus-24-1-0
export PYTHONPATH=$ENERGYPLUS_DIR:$PYTHONPATH
```

### 2. Get a building model (.idf)

Grab a DOE Commercial Reference Building from the EnergyPlus example files
folder (ships with the install) — e.g.
`ExampleFiles/RefBldgMediumOfficeNew2004_Chicago.idf`, or download one from
https://www.energycodes.gov/prototype-building-models. Copy it to
`models/baseline.idf`. You'll also need a weather file (`.epw`) — EnergyPlus
ships several under `WeatherData/`.

### 3. Install Ollama + pull a model

```bash
curl -fsSL https://ollama.com/install.sh | sh
ollama pull llama3.1        # or qwen2.5, mistral
ollama serve                # runs on localhost:11434
```

### 4. Python deps

```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
```

### 5. Run the closed loop

```bash
python src/orchestrator.py --idf models/baseline.idf --epw path/to/weather.epw --mode baseline
python src/orchestrator.py --idf models/baseline.idf --epw path/to/weather.epw --mode ai-closed-loop
```

This produces `data/baseline_run.csv` and `data/ai_run.csv`.

### 6. View savings dashboard

```bash
streamlit run dashboard/app.py
```

## Evaluation criteria → where it's addressed

| Criterion | Where |
|---|---|
| System Integration (30%) | `energyplus_wrapper.py` EMS callback loop, error/watchdog handling in `orchestrator.py` |
| Energy Efficiency Realized (25%) | `metrics.py` savings calc, `dashboard/app.py` |
| Thermal Comfort & Constraints (20%) | PMV/comfort tracking in `metrics.py`, constraint checks in `llm_agent.py` |
| Agentic Autonomy & Code Elegance (15%) | tool-calling design in `tools.py` + `llm_agent.py`, optional `mcp_server.py` |
| Presentation & Documentation (10%) | `docs/ARCHITECTURE.md`, this README |
